# dotfiles

System dotfiles worth backing up. Managed via symlinks from `~/` into this repo.

| Link | Source |
|---|---|
| `~/.zshrc` | `.zshrc` |
| `~/.gitconfig` | `.gitconfig` |
| `~/.config/*` | `.config/*` (individual symlinks for tracked items) |
| `~/.vscode/argv.json` | `.vscode/argv.json` |

Tracked configs: btop, fish, gh, helix, htop, karabiner, opencode, spicetify, starship, vscode argv.

Untracked configs live in `~/.config/` as real files, not in this repo.
